# AGENTS.md

Instructions and guidelines for AI agents developing and maintaining FastView.

## Project Architecture Overview

FastView is built using Swift, AppKit, and Swift Package Manager.

### Structure
- `Sources/FastView/Main.swift`: Application entry point (`AppDelegate`), menu bar creation, and command-line launch handling. The Dock icon is `Resources/AppIcon.png`, a package resource set before the run loop starts.
- `Sources/FastView/Resources/AppIcon.png`: Application icon (1024×1024).
- `Sources/FastView/Views/`:
  - `MainTabsViewController.swift`: The window's content: the browser tab (`MainSplitViewController`) and the closeable Favorites tab, with a tab bar (`MainTabBarView`) shown only while the Favorites tab is open (View → Favorites Viewer, ⇧⌘F; ⌘W closes it; ⌃Tab switches). `MainWindowController`'s key monitor hands keys to the Favorites tab while it shows.
  - `FavoritesViewController.swift`: Favorites tab: every favorite as a large thumbnail in an `NSCollectionView` grid (thumbnails at the cell's pixel size in steps, visible cells only, group `favorites-grid`), context menu (View Large, Show in Browser via `MainSplitViewController.reveal`, Show Info, copy, Remove from Favorites; ⌘F removes too). Double click or Return enlarges the selection to fill the tab (`EnlargedFavoriteView` with a `MainImageView` subclass: zoom, arrows step, Esc/Return/double click go back).
  - `GridSizePicker.swift`: `FavoritesGridSize` (Huge/Large/Medium/Small, UserDefaults; ⌘+/⌘− in the grid), `FavoritesGridMetrics` (columns and rows for an area) and the picker, whose segments draw a miniature of the grid area with the cells each size would show.
  - `MainSplitViewController.swift`: Core application coordinator, split view layout, and navigation state Random image (`showRandomImage`): a walk down from the location or selected folder/archive on `loadQueue`, picking one listed entry at random per level until an image, cancelled by any navigation in the pane. The 2nd view closes from its sidebar header button (`SidebarViewController.onClosePane`) or the button at the canvas's top right (`DualCanvasViewController.onCloseSecondPane`).
  - `SidebarViewController.swift`: Sidebar table view (`NSTableView`), cell configuration (`SidebarTableCellView`), custom keyboard input handling, and cell badge rendering (folders and archives show their name at bottom left). Visible thumbnails are requested once scrolling pauses; the debounce timer runs in common run-loop modes so pauses while dragging the scroller knob count too.
  - `MainImageView.swift`: Image canvas, zooming, panning, loading indicator overlay, and context menu (rotate/flip/reset orientation; a badge at top left shows while the orientation differs from the original, and `onOrientationChanged` keeps the combining canvas in sync). Cmd+Enter toggles full screen (View menu).
  - `ListSorter.swift`: Per-pane list sort options (name, modified date, favorites, viewed; persisted in UserDefaults; in the favorites list, modified means when each item was favorited) and the sort itself, run off the main thread. Modification dates come in bulk with the directory listing (`NavigationManager.contents`); dates still missing are read by listing each parent folder once, never one network round trip per file. The parent entry stays first and folders/archives stay ahead of images.
  - `CombinationStateManager.swift`: Saved combinations, one pretty-printed JSON `.fastview` file each in `~/Documents/FastView` (file I/O on a serial queue). Objects are stored in z order with normalized positions, region crop and colour adjustment; restoring re-runs detection on their source items through `ForegroundSource` (its own load queue, so pane image loads cannot cancel it). Preview thumbnails for the manager window are cached in `~/Library/Caches/FastView/CombinationPreviews`.
  - `CombinationStatesWindowController.swift`: Saved-combinations manager window (previews, search, rename, Show in Finder, Move to Trash).
  - `RestoreProgressView.swift`: Overlay with a progress bar shown over the canvas while a saved combination restores (pane images + objects; tracked in `MainSplitViewController`).
  - `ColorMatcher.swift`: Matches objects' colours to a reference object, led by skin tones (YCbCr skin test, grey-world retry for colour casts; per-channel gains match average skin colour), falling back to whole-object mean/spread matching.
  - `ObjectEffectsRenderer.swift`: Per-object effects (`ObjectEffects`, saved with combinations): Feather Edges (alpha shrunk and blurred) and Drop Shadow (blurred silhouette drawn under the object, straight down in canvas space), made off the main thread and cached by `CombiningCanvasView` per object image. Object context menu also has Match Colors and Light to Objects Below (`ColorMatcher` against the objects beneath, rendered with `renderObjects`).
  - `ObjectCarver.swift`: Carving canvas objects with a freehand outline (object context menu → Carve Out Object… keeps the inside, crops to it and runs Vision foreground detection on it; Erase Part of Object… clears the inside; New Object from Region… adds the detected foreground inside the outline as a new object on top; Undo Carving). The drawn outline first snaps to nearby edges of the object image (Core Image edge map, dynamic programming along the outline's normals; ⌥ on release skips it), and the snapped outline is what is saved. Carves are stored in object-image fractions and saved, so restoring re-applies them after detection and before colour adjustment; the canvas adjusts scale and position so the kept pixels stay put.
  - `FileInfoWindowController.swift`: Show Info panel (Cmd+I): thumbnail header, general/image/camera (EXIF)/contents/dates/library sections. Details are read off the main thread (archive entries through `DiskIOGate`) and the panel follows the selection while open.
  - `ImageCensor.swift`: Censoring areas of the shown image: styles (`CensorStyle`: Pixelate, Blur, Black Box, Censored Bar with a label kept upright on screen) applied to polygons in raw-image fractions, shapes (`CensorShape`: rectangle, ellipse, freehand), Vision face finding, and `CensorSettings` (UserDefaults). `MainImageView` runs censor mode (image context menu → Censor Parts of Image…, or View → Censor Parts of Image for the active pane) with `CensorToolbarView.swift` floating at the top; each drag censors at once, Undo/⌘Z steps back (10 levels, cleared on the next image), Esc or Done ends it. `MainWindowController`'s key monitor routes Esc and ⌘Z while censoring. Edits share `uneditedImage`/Restore Original Image with object removal and are lost when another image is shown; Save Image As… writes the shown image (orientation applied) as PNG or JPEG.
  - `CanvasOverlays.swift`: `HUDMessageView` (a brief message over a view; the status bar is hidden in full screen), `ImagePlaceholderView` (why an image area is empty, set through `MainImageView.showPlaceholder` and cleared by `setImage`) and `FileDropView` (the window's root view: dropped files go through `AppDelegate.open(path:pane:)`, with `MainSplitViewController.dropPane` picking the pane; rows dragged out of the app's own lists are not accepted back).
  - `FileActions.swift`: Show in Finder (an archive entry reveals its archive), Open in Default App, and `isOnDisk` (real files only, not archive entries or the (..) row). Move to Trash is `MainSplitViewController.moveToTrash` (not in favorites lists; registers Undo on the window's undo manager).
  - `KeyboardShortcutsWindowController.swift`: Help → Keyboard Shortcuts panel, from a static table; keep it in step with the menus and `MainWindowController`'s key monitor.
  - `StatusBarView.swift`: Status bar at bottom displaying location, index, count, and size metrics.
- `Sources/FastView/Inpaint/`: Removing an object from an image (image context menu → Remove Foreground Object from Background, which uses Vision's foreground mask (macOS 14+), or Remove Outlined Area from Background…, a freehand outline; Restore Original Image undoes it). `MainImageView` keeps the loaded image in `uneditedImage` and reports the edited one through `onImageEdited`, so the combining canvas shows it too; edits are not saved with combinations.
  - `ObjectRemover.swift`: Mask building, a crop around the hole (grown a little so edges go too), the chosen engine, and blending the fill back in. `ObjectRemovalEngine` is the Options → Object Removal choice (UserDefaults).
  - `PatchMatchInpainter.swift`: Built-in default: multi-scale PatchMatch with similarity-weighted voting, pyramid down until the hole is a few pixels across; works on crops up to 1024 px. Slow in debug builds (~30 s for a large hole vs ~1.5 s in release).
  - `LamaInpainter.swift`: Optional LaMa model (Core ML, Apache 2.0 conversion from huggingface.co/Jia-Liu/big-lama-coreml, ~95 MB zip): downloaded, unpacked with `ditto` and compiled into `~/Library/Application Support/FastView/Models/LaMa.mlmodelc`, deletable from the Options menu. Inputs are float arrays (image 0...1, mask 1 = hole, 800×800); output 0...255.
  - `ModelDownloadPanel.swift`: `DownloadableModel` (the optional models: download, cancel, delete, size) and its confirmation and progress panel. Options → AI Models downloads or deletes each model; Options → Object Removal picks the engine.
- `Sources/FastView/Cache/`:
  - `MemoryLRUCache.swift`: In-memory image cache supporting Low Memory Mode (capped at 10 items when active).
  - `SQLiteCache.swift`: SQLite database (`fastview_cache.sqlite`) for favorite persistence and directory structure caching.
  - `ThumbnailGenerator.swift`: Background and priority thumbnail extraction and recursive preview peeking (`peekFirstImage`, cancellable). Selecting a folder or archive loads its preview image into the full view through `loadFullImage`. Thumbnail ops are keyed by size and item, so the sidebar (256 px) and the Favorites grid (larger) never share one; only 256 px archive thumbnails go to `ArchiveThumbCache`.
  - `DirectoryCache.swift`: Fast in-memory caching of directory file item lists.
  - `DirectoryWatcher.swift`: FSEvents watcher for the folders the panes list (not archives or favorites). `MainSplitViewController` re-lists a changed folder in the background, bypassing the SQLite listing cache, and `SidebarViewController.setRefreshedItems` swaps the list in place keeping the selected item and its place on screen (when it was deleted, the row now in its place is selected). Folders opened from the listing cache are re-listed once the same way, and changed files get their thumbnails read again.
  - `ArchiveThumbCache.swift`: Local on-disk cache of RAR archive thumbnails and image lists (`~/Library/Caches/FastView/ArchiveThumbs`, one JSON + JPEG per archive keyed by a hash of its path), validated by archive size and modification date. ZIP archives are not cached: their directory and preview are read by range, which is as quick.
- `Sources/FastView/Archive/`:
  - `ArchiveReader.swift`: Archive entry-list cache, listing, and entry extraction, all requested from `ArchiveService`.
  - `ArchiveService.swift`: In-process archive I/O, one request at a time: open-archive cache; list/extract/preview/prefetch requests, each stopping at its next read once its `isCancelled` check turns true. Network RAR archives are read whole first, and a stopped read resumes where it stopped.
  - `ZipDirectory.swift`: ZIP central-directory parser and ranged entry reads (ZIP archives are never read whole).
  - `RarArchive.swift`: unrar header scan and entry extraction, with progress and cancellation.
  - `ArchivePreview.swift`: Preview-image choice and thumbnail downscaling, shared by the archive service and the sidebar.
  - `DiskIOGate.swift`: Serialises disk I/O; interactive work is admitted before background work.
  - `NavigationManager.swift`: Navigation history, current location tracking, and path location resolution.
  - `FileLogger.swift`: Performance logging.

## Code Conventions & Directives

1. **Safety & Nullability**: Swift optionals and guard statements should be preferred for clean error handling.
2. **I/O Operations**: Do not perform synchronous disk/network I/O on the main thread. Always offload I/O to appropriate operation queues (`priorityQueue` or `thumbnailQueue` in `ThumbnailGenerator`). Archive I/O goes through `ArchiveService` and takes an `isCancelled` check so a priority operation can stop it.
3. **UI Updates**: All UI changes (updating table views, views, menu items, or status bar) must be dispatched back to `DispatchQueue.main`.
4. **Badges & Overlay Formatting**: Overlay badges in `SidebarTableCellView` use SF Symbols with symbol configuration (e.g. `pointSize: 28, weight: .bold`) inside 44x44 pt frames.
5. **Opening Paths**: Anything the user opens by path (File > Open, Open Recent, a drop) goes through `AppDelegate.open(path:pane:)` and `MainSplitViewController.openPath`, which read the path off the main thread and choose the selection (`selectionTarget`). A selection target that is gone falls back to the first item, except during a combination restore.
6. **Menu Shortcuts**: A shortcut with Shift uses an uppercase key equivalent (`"S"` with `.command` is ⇧⌘S), as in the standard Mac menus, so it cannot land on the unshifted item. Menu commands act on the active pane (`activeImageView`), and on the Favorites tab's selection while it shows (`AppDelegate.currentItem`).
7. **Running the App in Tests**: `CFFIXED_USER_HOME` isolates caches but not preferences, which still reach the real `FastView` domain. Run a renamed copy of the executable, with `FastView_FastView.bundle` beside it, so its preferences domain differs.
